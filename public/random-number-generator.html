What Is a Random Number?

A random number is a number chosen from a pool of limited or unlimited numbers that has no discernible pattern for prediction. The pool of numbers is almost always independent from each other. However, the pool of numbers may follow a specific distribution. For example, the height of the students in a school tends to follow a normal distribution around the median height. If the height of a student is picked at random, the picked number has a higher chance to be closer to the median height than being classified as very tall or very short. The random number generators above assume that the numbers generated are independent of each other, and will be evenly spread across the whole range of possible values.

What Is a Random Number Generator?

A random number generator, like the ones above, is a device that can generate one or many random numbers within a defined scope. Random number generators can be hardware based or pseudo-random number generators. Hardware based random-number generators can involve the use of a dice, a coin for flipping, or many other devices.

Pseudo-Random vs. True Random Numbers

A pseudo-random number generator is an algorithm for generating a sequence of numbers whose properties approximate the properties of sequences of random numbers. Computer based random number generators are almost always pseudo-random number generators. Yet, the numbers generated by pseudo-random number generators are not truly random. Likewise, our generators above are also pseudo-random number generators. The random numbers generated are sufficient for most applications yet they should not be used for cryptographic purposes. True random numbers are based on physical phenomena such as atmospheric noise, thermal noise, and other quantum phenomena. Methods that generate true random numbers also involve compensating for potential biases caused by the measurement process.

Frequently Asked Questions (FAQ)

What is a random number generator?

A random number generator (RNG) is a tool that produces one or more numbers from a defined range in a way that has no predictable pattern. You set a lower limit and an upper limit, and the generator picks values from that range.

How do I generate a random number between 1 and 100?

Enter 1 as the lower limit and 100 as the upper limit in the first generator, then click Generate. The tool returns a random integer from 1 to 100. The same steps work for any other range, such as 1 to 10 or 1 to 1000.

Can this tool generate random decimal numbers?

Yes. Use the Comprehensive Version, set the result type to Decimal, and choose the precision you need. Precision can be set up to 999 digits.

Can I generate several random numbers at once?

Yes. In the Comprehensive Version, enter how many numbers you want (up to 999) in the Generate field. You can then choose whether duplicates are allowed and whether the results should be sorted in ascending or descending order.

How do I generate random numbers without repeats?

Set the quantity to more than one in the Comprehensive Version, then choose No under "Allow duplication in results?". Every number in the output will then be unique. The range must contain at least as many possible values as the amount you request.

Are the numbers truly random?

No. Like almost all computer-based generators, this tool is a pseudo-random number generator. It uses an algorithm to produce numbers that behave statistically like random numbers. This is sufficient for most everyday uses, but true randomness comes from physical sources such as atmospheric or thermal noise.

Can I use these random numbers for passwords or cryptography?

No. Pseudo-random numbers from this tool should not be used for passwords, encryption keys, or other security purposes. Use a cryptographically secure random number generator for those cases.

How large can the numbers be?

The integer generator handles very large integers of up to a few thousand digits, and the Comprehensive Version supports numbers with up to 999 digits of precision.

Can I use this tool to pick a raffle or giveaway winner?

Yes. Number your entries from 1 to the total count, set that as the range, and generate one number. For several winners, generate multiple numbers with duplicates turned off so nobody wins twice.

Is every number in the range equally likely?

Yes. The generators assume each number is independent of the others and spread results evenly across the whole range, so every value has the same chance of being picked. This is called a uniform distribution.

What is the difference between a random number and a random number following a distribution?

A uniform random number is equally likely to be anywhere in the range. Some real-world data, such as student heights, follows a normal distribution where values near the average are more likely. The generators on this page produce uniform results, not normally distributed ones.
