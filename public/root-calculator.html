What Is a Root in Mathematics?

In mathematics, the nth root of a number is a value that, when raised to the power n, produces the original number.

For example, the square root of 25 is 5 because 5 × 5 = 25.

How to Calculate a Square Root

A square root is a number that multiplied by itself gives the original number.

Example: √144 = 12 because 12 × 12 = 144.

How to Calculate an nth Root

The nth root of a number a can be calculated using the formula:

nth root of a = a1/n

Example: The fourth root of 81 is 3 because 3 × 3 × 3 × 3 = 81.

Frequently Asked Questions

1. What is a square root?

A square root is a number that multiplied by itself equals the original number.

2. What is a cube root?

A cube root is a number that multiplied by itself three times equals the original number.

3. Can you calculate the square root of a negative number?

Negative numbers do not have real square roots. They have complex roots.

4. What is the square root of 2?

The square root of 2 is approximately 1.41421356.

5. What is the fourth root of 81?

The fourth root of 81 is 3.

6. Can cube roots handle negative numbers?

Yes. The cube root of -8 is -2.
