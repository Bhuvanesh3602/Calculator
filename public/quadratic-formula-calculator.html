What Is a Quadratic Equation?

In algebra, a quadratic equation is any polynomial equation of the second degree with the following form:

ax2 + bx + c = 0

where x is an unknown, a is referred to as the quadratic coefficient, b the linear coefficient, and c the constant. The numerals a, b, and c are coefficients of the equation, and they represent known numbers. For example, a cannot be 0, or the equation would be linear rather than quadratic. A quadratic equation can be solved in multiple ways, including factoring, using the quadratic formula, completing the square, or graphing. Only the use of the quadratic formula, as well as the basics of completing the square, will be discussed here (since the derivation of the formula involves completing the square). Frequently Asked Questions (FAQ)

What is the quadratic formula?

The quadratic formula is x = (–b ± √(b2 – 4ac)) / 2a. It gives the solutions (roots) of any quadratic equation written in the standard form ax2 + bx + c = 0, where a is not zero.

How do I use this quadratic formula calculator?

Write your equation in the form ax2 + bx + c = 0, type the values of a, b and c into the three boxes at the top of the page, and click Calculate. Fractional values such as 3/4 can be entered directly.

What is the discriminant?

The discriminant is the expression b2 – 4ac found under the square root in the quadratic formula. It tells you what kind of solutions to expect without fully solving the equation.

How many solutions can a quadratic equation have?

If the discriminant is positive, there are two distinct real solutions. If it is zero, there is exactly one real solution (a repeated root). If it is negative, there are no real solutions, but there are two complex solutions that are conjugates of each other. For example, the default values in the calculator (a = 1, b = 1, c = 1/4) give a discriminant of 0, so the only solution is x = –1/2.

Why can't a be zero in a quadratic equation?

If a is 0, the x2 term disappears and the equation becomes bx + c = 0, which is a linear equation, not a quadratic one. The quadratic formula also divides by 2a, so a = 0 would require dividing by zero.

Can b or c be zero?

Yes. Only a must be non-zero. If b = 0 the equation is ax2 + c = 0, and if c = 0 it is ax2 + bx = 0. The quadratic formula still works in both cases.

What are the roots of a quadratic equation?

The roots (also called solutions or zeros) are the values of x that make the equation true. Graphically, real roots are the x-values where the parabola crosses the x-axis.

What other methods can solve a quadratic equation?

Besides the quadratic formula, a quadratic equation can be solved by factoring, by completing the square, or by graphing. The quadratic formula works for every quadratic equation, while factoring only works easily when the roots are simple numbers.

How is the quadratic formula derived?

It comes from completing the square on ax2 + bx + c = 0. Divide by a, move the constant to the right side, add (b/2a)2 to both sides, write the left side as a perfect square, take the square root of both sides, and solve for x. The full step-by-step derivation is shown above.

How do I find the axis of symmetry and vertex of a parabola?

The axis of symmetry of y = ax2 + bx + c is the vertical line x = –b / 2a. The vertex lies on this line, and its y-value is found by substituting x = –b / 2a back into the equation.

Can you show an example of solving a quadratic equation?

For x2 – 5x + 6 = 0, a = 1, b = –5 and c = 6. The discriminant is (–5)2 – 4(1)(6) = 1, so x = (5 ± 1) / 2, which gives x = 3 and x = 2.

Where is the quadratic formula used in real life?

It is used to calculate areas, projectile trajectories, speed, and other situations in physics, engineering, finance and design where a quantity changes according to a squared term.
